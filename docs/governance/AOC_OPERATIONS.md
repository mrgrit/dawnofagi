에이전트가 이상하게 굴 때 **무엇을 보고 무엇을 누르는가.**

## 0. 한 줄 요약

```
통제 평면(P0)  "이건 하지 마"       ← 미리 막는다
관제(P3)       "지금 뭘 했지?"      ← 벌어진 걸 보고 대응한다
```

둘 다 필요하다. 사전 통제만 있으면 뚫렸을 때 모르고, 관제만 있으면 뚫리고 나서 안다.

## 1. 지금 회사가 어떤 상태인가 — 픽셀 오피스

```bash
make office-bg       # 백그라운드 기동 — SSH 를 끊어도 살아 있다 (서버는 이걸 써라)
make office-stop     # 중지
make office          # 포그라운드 (Ctrl-C 로 종료. 터미널 닫으면 같이 죽는다)
```

기동하면 **접속 주소를 출력한다.** 헤드리스 서버에 브라우저가 없어도 상관없다 —
그 주소를 **당신 PC 브라우저**에 치면 된다.

```
$ make office-bg
픽셀 오피스
  http://192.168.0.108:8800/   ← 브라우저에서 여기로
```

로컬로만 묶으려면 `make office-bg HOST=127.0.0.1`, 포트는 `PORT=9000`.
로그는 `var/aoc/serve.log`.

**안 열릴 때 확인 순서**

```bash
ss -ltn | grep 8800                       # 1. 서버가 떠 있나
curl -s -o /dev/null -w '%{http_code}\n' http://<IP>:8800/   # 2. 서버에서 자기 자신에 붙나
```

2번이 200 인데 브라우저에서 안 되면 **당신 PC 와 이 서버가 같은 망이 아니거나**
중간에 방화벽이 있다. `ip -4 addr` 로 서버 IP 대역을 보고 맞춰라.

> 인증이 없다. 이 콘솔은 전 에이전트의 텔레메트리·케이스·자산 이름을 그대로 보여주고,
> el34 브리지(10.20.x)에도 함께 노출된다. 신뢰하는 망에서만 열어라.

건물 하나가 회사다. 아이소메트릭 사옥이고, **네 단계**로 파고든다.

```
사옥(전 층) → 층(본부) → 방(존) / 부서 자리(팀) → 사람(실행 트레이스)
```

| 보이는 것 | 뜻 | 어디서 온 값인가 |
|---|---|---|
| **층** | 본부 4개 | `org/divisions/` |
| 층 안 **뒤쪽 방들** | el34 존. 왼→오른쪽으로 **리스크 등급 순** (L0 로비 → L3 통제) | EG `Zone` + `MAPS_TO sec:Lx` |
| 방 **칸막이 높이·색** | 보안등급. 높을수록 진하다 | EG `SecurityLevel` |
| 방 사이 **주황 문** | pipe = 존 사이의 문(PEP). 존을 넘으면 여기를 지난다 | EG `Zone.is_gate` |
| 방이 **흐리고 "미사용"** | 그 본부가 안 쓰는 존. **없는 게 아니라 업무가 없는 것** | 팀 매니페스트 ∪ 텔레메트리 |
| 층 안 **앞쪽 데스크 섬** | 팀. 팀당 한 섬 | `org/divisions/<본부>/<팀>/team.yaml` |
| 오른쪽 **휴게실** | 층마다 하나. 진행 중인 스팬이 없는 사람이 있는 곳 | 스팬 없음 |
| 왼쪽 **코어** | 계단·엘리베이터 (건물 뼈대) | — |

에이전트(아바타) 하나하나가 이렇게 읽힌다:

| 부위 | 뜻 |
|---|---|
| **상의 색** | 소속 본부 |
| **깃·바지 색** | 소속 팀 |
| **모자** | 자율화 등급 (A0 회색 → A3 보라. 높을수록 사람 승인이 덜 필요) |
| **명찰** | 지금 쓰는 모델 (OPUS/SONNET/HAIKU/LOCAL) |
| **발밑 링** | 상태 — 초록=작업, 회색=대기, 빨강=경보, 주황=일시중지, 보라=격리, 진빨강=종료 |
| **발밑 품질 막대 3칸** | judge 3축 (근거·완결·경로). 회색이면 아직 판정 안 됨 |
| **얼굴**(머리·안경·수염) | `agent_id` 고정 해시 — 같은 에이전트는 늘 같은 얼굴이다 |

### 사람이 어디 서 있는가 = 그 순간 무엇을 했는가

이게 이 화면의 핵심 규칙이다. **소속으로 세우지 않는다.**

| 어디 | 언제 |
|---|---|
| **방 안** | 그 시각 스팬이 **액션 게이트를 지나** 그 존의 자산을 만졌을 때 |
| **자기 자리**(팀 데스크) | 게이트를 안 지난 스팬. 생각 중(chat)이거나 EG 조회 중 |
| **휴게실** | 스팬이 아예 없음 = 아무 일도 안 하는 중 |

존 경계는 문(pipe·PEP)이다. **게이트를 지난 적이 없으면 문을 통과한 적도 없다.**
그래서 워커 루프의 필수 단계(`eg.search`·`eg.record`)는 dmz 자산(EG DB)을 만지지만
방으로 걸어가지 않는다 — 대신 자기 자리에서 그 방으로 **가는 선**이 그려진다
(원격 조회). run 마다 두 번씩 일어나는 일이라 왕복시키면 의미 있는 존 이동이 묻힌다.

### 방·부서 안으로 들어가면

집기가 곧 자산이고, 종류로 성격이 구분된다:

| 집기 | 뜻 |
|---|---|
| 서버랙 | `kind: system` |
| 캐비닛 | `kind: data` |
| 워크벤치 | `kind: tool` |
| 터미널 | `kind: mcp` |
| **붉은 테** | `irreversibility: irreversible` — 되돌릴 수 없는 것은 눈에 띄어야 한다 |
| 왼쪽 게시판 | **업무** (L3 SOP) |
| 오른쪽 게시판 | **권한** (그 층의 실효 경계) |

**사람은 자기가 만지는 집기 앞에 서고, 그 집기와 선으로 이어진다.** 선 색이 게이트
판정이다. "통제 구역에 들어갔다"가 아니라 "**재무 원장을 읽는 중이고 사람 승인이
걸렸다**"가 보인다.

### 시계는 실시간이 아니라 이벤트 단위다

도구 호출은 1ms, chat 은 5분이다. 실시간 배속으로 재생하면 섹터에 들어갔다 나오는
순간이 한 프레임도 안 걸린다. 그래서 타임라인 눈금이 **스팬의 시작·끝 시각**이고,
`⏭` 로 이벤트를 하나씩 밟는다. 표시되는 시각은 언제나 진짜 타임스탬프이고, 직전
이벤트와의 간격(`+5분`)을 같이 띄운다 — 압축한 건 관측 간격이지 시각이 아니다.

**아무것도 안 움직인다면 정상이다.** 이 화면은 실제 이벤트가 있을 때만 바뀐다.
장식용 애니메이션은 넣지 않았다 — 움직임 = 진짜 일어난 일.

### 브라우저가 없는 서버에서 화면 확인하기

```bash
make office-preview                       # var/aoc/preview/building.png
make office-preview VIEW=floor DIV=corp   # 특정 층
```

`index.html` 의 캔버스 호출을 그대로 받아 적어 PNG 로 다시 그린다. 브라우저 렌더와
픽셀 단위로 같지는 않다 — **구도·배치·색을 보기 위한 것**이다.
`pip install quickjs pillow` 가 필요하고, 둘 다 **배포 의존이 아니다.**

## 2. 뭔가 잘못됐나 확인하기

```bash
make aoc             # 수집 → 탐지 → 트리아지 (케이스가 있으면 만든다)
make aoc-cases       # 케이스 목록
```

케이스 한 줄은 이렇게 읽는다:

```
🔴 case-95fb118ac3  [security] critical  corp-admin-clerk-01  행동 게이트가 pay.execute 을 차단했다
   ↑ 심각도          ↑ 축                 ↑ 누가                ↑ 무슨 일
```

**축**은 셋뿐이다: `security`(보안) · `quality`(품질) · `alignment`(정렬 — 시키지 않은 짓).

**심각도**는 자동으로 계산된다:

```
심각도 = 그 행동의 비가역성  ×  건드린 자산의 보안등급
```

읽기(read)보다 지우기(irreversible)가 무겁고, 초안 문서(L1)보다 재무 원장(L3)이 무겁다.
사람이 감으로 매기지 않는다. **분류가 안 된 자산은 최고 등급으로 친다** — "모르면 안전"은
사고를 만든다.

상세를 보려면:

```bash
make aoc-cases ID=case-95fb118ac3
```

## 3. 대응하기

```bash
make aoc-respond ID=case-95fb118ac3
```

관제가 **권고한 것만** 집행된다. 그리고 여기서 한 번 더 갈린다:

| 되돌릴 수 있는 것 → **즉시 집행** | 되돌릴 수 없는 것 → **승인 큐로** |
|---|---|
| `pause` 일시중지 (권한은 그대로) | `kill` 강제 종료 + A0 강등 |
| `isolate` 샌드박스 격리 | `revoke_credentials` 자격증명 회수 |
| `block_tool` 그 도구만 뺏기 | `report_regulator` 규제 보고 |
| `rollback` 산출물 격리 보관 | |
| `escalate_hitl` 사람에게 올리기 | |

오른쪽 칸은 **당신이 누르기 전에는 절대 실행되지 않는다.**

```bash
make hitl            # 승인 큐 확인 — 오른쪽 칸이 여기 쌓인다
```

> **`rollback` 은 지우지 않는다.** 산출물을 `var/aoc/quarantine/<케이스>/` 로 옮긴다.
> 사고 산출물은 증거다.

특정 플레이북만 돌리고 싶으면:

```bash
make aoc-respond ID=case-... PB=pause,isolate
```

## 4. 급할 때 — 킬 스위치

```bash
make aoc-control                                          # 현재 상태
dawn-aoc control pause  <agent-id> --by human:<당신이름>    # 멈춰
dawn-aoc control isolate <agent-id> --by human:<당신이름>   # 격리
dawn-aoc control kill    <agent-id> --by human:<당신이름>   # 끝내
dawn-aoc control resume  <agent-id> --by human:<당신이름>   # 풀어줘
```

**`pause` 와 `kill` 은 다르다.**

| | 실행 | 권한 | 자율화 | 해제 |
|---|---|---|---|---|
| `pause` | 멈춤 | **그대로** | 그대로 | 아무나 |
| `kill` | 멈춤 | 그대로 | **A0 강등** | **사람만** (`--by human:...`) |
| `revoke` | 안 멈춤 | **무효화** | 그대로 | 재발급 필요 |

멈추는 것(stop)과 권한을 뺏는 것(de-authorize)은 **다른 행동**이다.
"일단 멈춰"가 곧 "권한 회수"가 되면, 사소한 오작동에도 재기동 비용이 커져
결국 아무도 멈추지 않게 된다.

**에이전트는 이 계층을 못 건드린다.** `ctl.*` 도구는 전사 게이트에서 영구 차단이고,
코드에도 실행부가 없다. 정책 파일을 잘못 고쳐도 돌아갈 경로가 없다.

## 5. 사고가 났다 — 되감아 보기

```bash
make aoc-replay T=<trace-id>          # 또는 픽셀 오피스에서 슬라이더를 끌기
```

트레이스 하나로 이만큼이 복원된다:

```
누가       corp-admin-clerk-01 (corp-admin/corp, EG org:ga, persona=corporate, A1, zone=user)
무엇을     pay.execute
어떤 판정  gate=block  sev=6  근거: 통제 평면이 차단한 도구; 비가역 스킬 — 사전 인간 승인 필요
무엇에     asset:payment
사람은     hitl-16e8afd5aa → pending
언제       +5ms
```

EU AI Act 12조가 요구하는 건 "로그가 있다"가 아니라
**"로그만으로 그때 무슨 일이 있었는지 복원된다"** 이다.

## 6. 잘 돌아가고 있나 — KPI

```bash
make aoc-kpi
```

| 지표 | 방향 | 뜻 |
|---|---|---|
| 태스크 성공률 | ↑ | 시킨 일을 끝냈나 (`eg_record` 까지) |
| HITL 개입률 | ↓ | 사람을 얼마나 불렀나. 높으면 권한 설계가 잘못됐다 |
| 오탐율(승인 거부) | ↓ | 올릴 필요 없던 걸 올렸나. 높으면 사람이 곧 무조건 승인하게 된다 |
| 할루시네이션율 | ↓ | judge 근거 점수 70 미만 비율 |
| MTTD / MTTR | ↓ | 탐지까지 / 대응까지 걸린 시간 |
| 가드레일 적중 | — | 많고 적음보다 **미탐이 0 인지**가 중요하다 |

**표본이 없으면 "표본 없음"으로 뜬다.** 0% 라고 쓰지 않는다 —
데이터 없이 목표 달성으로 보이는 대시보드는 회사를 잘못된 방향으로 운전한다.

### 자율화 등급은 KPI 로만 올린다

```
⬆ 승급   해당 등급의 KPI 조건을 다 채웠을 때만 (감으로 올리지 않는다)
⬇ 강등   critical 인시던트 발생 즉시 A0. 조건 없음.
```

`make aoc-kpi` 하단에 지금 누가 승급 가능한지, 왜 안 되는지가 나온다.

## 7. 판정기(judge)는 왜 따로인가

**`make aoc` 가 실업무 run 을 자동으로 판정한다.** 따로 켤 필요 없다.

```bash
make aoc                    # 수집 → 탐지 → 트리아지 (+ 실업무는 judge 자동)
dawn-aoc scan --no-judge    # 판정 끄기 (모델 호출 없이)
dawn-aoc scan --judge       # 드릴·레드팀까지 전부 판정
```

**실업무(`purpose == "work"`) 만 판정한다.** 품질 축의 목적은 게이트가 못 잡는
"조용히 잘못한 것"을 잡는 것이라 이상이 잡힌 run 만 보면 취지에 어긋나고, 반대로
드릴·레드팀은 **일부러 실패하는 실행**이라 채점해 봐야 할루시네이션율만 오염된다.
같은 run 을 두 번 판정하지 않고(`var/aoc/judge/<trace_id>.json`), 화면 조립은
읽기만 한다 — `/api/state` 가 모델을 부르면 화면 열 때마다 돈이 나간다.

산출물을 만든 모델과 **다른 모델**이 채점한다. 자기 답안을 자기가 채점하면 감사가 아니다.

> **정책 id 가 다른 것으로는 부족하다.** `model:gptoss` 와 `model:openlocal` 은
> 서로 다른 정책이지만 둘 다 `$LOCAL_LLM_MODEL` 로 풀려서, 한동안 **모델이 자기
> 산출물을 채점**하고 있었다(2026-08-02 발견). 지금은 **풀린 모델까지 비교**하고,
> 같으면 판정을 내지 않는다 — 틀린 점수보다 "판정 못 했다"가 낫다.
> 판정 전용 정책은 `model:judge` (`.env` 의 `LOCAL_JUDGE_MODEL`) 이고,
> 업무용으로는 배정하지 않는다.

세 축으로 본다:

| 축 | 묻는 것 |
|---|---|
| **groundedness** | 근거를 대고 말하나. 출처 없이 단정한 데가 있나 |
| **completeness** | 요구한 걸 다 채웠나. 빼먹고 완료라고 했나 |
| **trajectory** | 절차를 지켰나. 건너뛴 단계가 있나 |

70 미만이면 케이스가 만들어진다 (축 `quality`).

**KPI 는 실업무만 센다.** 드릴·레드팀 run 은 일부러 차단되어 ④ eg_record 에 도달하지
않으므로, 같이 집계하면 "레드팀이 잘 막혔다"가 "일을 못 한다"로 뒤집혀 읽힌다.
실제로 태스크 성공률 41.9% 의 미완 25건 중 21건이 레드팀 시도였다. 지금은 run 마다
목적 태그(`dawn.run.purpose`)가 붙는다:

| 목적 | 누가 | KPI |
|---|---|---|
| `work` | 실업무 (기본값) | **센다** |
| `drill` | 리허설·인시던트 드릴 | 뺀다 |
| `redteam` | 공격 시뮬 | 뺀다 |
| `demo` | 시연 | 뺀다 |
| `unknown` | 목적 태그 이전 트레이스 | 뺀다 |

몇 건을 뺐는지 KPI 마다 표시한다 — 조용히 빼면 그 자체가 거짓말이다.
탐지 지표(가드레일 적중·MTTR)는 **드릴을 포함해서** 센다. 드릴은 탐지력을 재는
정당한 표본이다.

## 8. 흔한 상황 대처표

| 상황 | 먼저 볼 것 | 그다음 |
|---|---|---|
| 아바타가 빨간 링 | `make aoc-cases` | 심각도 확인 → `make aoc-respond` |
| 승인 요청이 너무 많다 | `make aoc-kpi` HITL 개입률 | 팀 `gate.yaml` 의 `hitl.require_on` 을 좁혀라 |
| 에이전트가 엉뚱한 소리를 한다 | `make aoc-judge` | groundedness 낮으면 `work/*_WORK.md` SOP 를 보강 |
| 같은 도구만 반복한다 | 케이스 `tool_loop` | `pause` → 업무 지시를 좁혀서 재실행 |
| 뭔가 새는 것 같다 | `dawn-aoc guard output "<의심 텍스트>"` | 걸리면 즉시 `pause` + `rollback` |
| 지금 당장 멈춰야 한다 | — | `dawn-aoc control kill <id> --by human:<이름>` |

## 9. 알아둘 것

- **관제는 별도 계층이다.** 감시받는 에이전트가 자기 감시 결과를 고칠 수 없다.
- **행동 게이트를 관제가 다시 판정하지 않는다.** 실행 계층(P2)이 내린 판정을 그대로 읽는다.
  두 판정이 갈라지면 관제는 실행을 못 막는다.
- **화면의 모든 값은 실제 텔레메트리다.** 채워 넣은 숫자는 하나도 없다.
  값이 없으면 화면도 빈다.
- **미탐이 오탐보다 비싸다.** 모르는 조건·미분류 자산은 보수적으로 판정한다.

## 10. 파일이 어디 쌓이나

```
var/traces/<trace-id>.jsonl      원본 스팬 (P2 가 씀)
var/aoc/runs.jsonl               정규화된 실행 단위
var/aoc/cases/<case-id>.json     관제 케이스
var/aoc/control/<agent-id>.json  제어 상태 (킬 스위치)
var/aoc/responses.jsonl          대응 집행 이력
var/aoc/quarantine/<case-id>/    롤백된 산출물 (지우지 않고 보관)
var/aoc/state.json               콘솔 스냅샷 (픽셀 오피스가 읽음)
var/hitl/<id>.json               승인 큐 (append-only)
```

전부 `var/` 아래고 git 에 올라가지 않는다. 감사 증거가 필요하면 이 디렉터리를 보관하라.
