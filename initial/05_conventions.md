# 05. 컨벤션·가드레일 (참조 — 예외 없이 준수)

> 이 규칙은 the dawn of AGI가 스스로 만든 AOC 원칙을 자사 구축에 먼저 적용하는 것이다. 우리가 먼저 지킨다.

## 보안 가드레일 (최우선)
1. **시크릿 하드코딩 금지.** API 키·비밀번호·토큰은 환경변수/볼트. 저장소에 커밋 금지(.gitignore, pre-commit 훅으로 차단).
2. **파괴적 작업은 게이트.** 삭제·배포·결제·외부발송·방화벽변경 등 비가역 작업은 사람 승인(HITL) 또는 명시적 확인 후 실행. skill_preview가 HIGH/destructive면 자동으로 게이트.
3. **최소권한.** 각 에이전트·서비스는 필요한 범위만. el34 존 경계를 넘는 접근은 pipe 게이트를 통과하고 로그를 남긴다.
4. **테넌트 격리.** 자사=테넌트 #0. 멀티테넌트 확장을 염두에 두고 데이터·EG를 네임스페이스로 분리. 크로스테넌트 접근 코드 금지.
5. **민감등급(L3) 로컬 처리.** 인사·재무 개인정보는 클라우드 모델에 전송 금지. 로컬 모델만.
6. **악성코드·공격코드 금지.** 오펜시브(레드팀)조차 el34 취약웹(zone:int)에 스코프 한정. 실 자산·외부 대상 공격 코드 작성 금지.

## 감사·로깅 (EU AI Act 정렬)
- 모든 AI 지원 의사결정은 **사후 재구성 가능** 수준으로 로깅(프롬프트·계획·도구 I/O·결과). OTel 스팬으로.
- 로그 자체가 민감정보이므로 PII 마스킹을 수집 계층에 내장.

## 코딩 컨벤션
- **작게 커밋.** 기능 단위. 커밋 메시지에 `[Pn][DoD-x]` 태그.
- **테스트.** 핵심 로직은 테스트 동반. CI에서 lint+test 통과해야 머지.
- **문서화.** 각 서비스에 README(실행법·의존성·환경변수). 새 MCP·에이전트는 인터페이스 문서.
- **의존성 추가.** 새 외부 패키지는 BUILD_LOG.md에 이유 기록. 라이선스 확인.
- **재현성.** 록파일 커밋. 환경은 컨테이너/스크립트로 재현 가능하게.

## 품질 가드레일 (AOC 품질 인시던트 정렬)
- 고객 대면 산출물은 근거(출처) 첨부 + 할루시네이션 평가 통과 후 전달.
- 에이전트 산출 코드도 관제 대상: 무한 루프·과도한 토큰·비정상 도구 시퀀스는 서킷 브레이커로 차단.

## EG 우선 원칙
- 에이전트 행동을 바꾸려면 코드가 아니라 EG(Persona/Policy)를 수정한다. 하드코딩된 행동 규칙 대신 eg_search로 정책을 조회하게 설계.
- 새 규정·페르소나가 필요하면 EG 시드에 노드를 추가하고 validate.py로 검증 후 주입.

## 자기검증 의무
- 각 지시문(Pn) 완료 시 DoD 체크 + 자기검증 실행. 결과를 BUILD_LOG.md에 append.
- 실패 시 다음 단계로 넘어가지 말고 원인 기록 후 수정.

## 모호하면 멈춤
- 스펙 모호·파괴적 결정·보안 판단이 필요하면 QUESTIONS.md에 남기고 사람 답을 기다린다. 추측으로 진행하지 않는다.
